Three original, three-line office jokes about performance reviews, Slack threads, and a printer with better boundaries than the rest of us. A tiny Node 22 TypeScript program prints them to stdout — no dependencies, no network, no files read.

## Run it

With Node 22 (built-in TypeScript type stripping, no install needed):

```sh
node --experimental-strip-types main.ts
```

Or with `tsx`:

```sh
npx tsx main.ts
```

Expected output: three jokes, each on at most three consecutive lines, with a blank line between them and nothing else.
